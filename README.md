🌐 Interactive Portfolio Website
📌 Project Overview

This project is an interactive personal portfolio website created as part of a UI / Frontend Challenge.
The main objective of this project is to showcase my UI sense, design thinking, creativity, and attention to detail through a clean and user-friendly web interface.

The website presents my personal information, learning journey, and inspirations in a structured and visually engaging way.

🎯 Purpose of the Project

To demonstrate understanding of frontend structure and UI design

To create a visually appealing and interactive portfolio

To practice organizing content with good visual hierarchy

To build a responsive website suitable for all devices

🛠️ Tools & Technologies Used

HTML5 – Structure of the website

CSS3 – Styling, layout, responsiveness, and animations

JavaScript – Basic interactivity and enhancements

Lovable (No-Code Tool) – Used initially to prototype and visualize UI concepts

GitHub – Version control and code hosting

Note: The project focuses on UI/UX understanding and frontend structure rather than complex backend logic.

✨ Features Implemented
🔹 Sticky Header with Navigation

Header remains visible while scrolling

Easy navigation to different sections of the website

🔹 Personal Information Section

Name, role, tagline, and a short introduction

Clear presentation to establish identity

🔹 Animated Hero Section

Subtle animations for text and elements

Enhances visual appeal without being distracting

🔹 “My Story” Section

Brief description of my learning journey and mindset

🔹 Quote Section

Reflects my perspective as a student and learner

🔹 Interactive Image Gallery

Displays inspirations, hobbies, or milestones

Includes hover effects for better engagement

🔹 Responsive Design

Works smoothly on desktop, tablet, and mobile screens
